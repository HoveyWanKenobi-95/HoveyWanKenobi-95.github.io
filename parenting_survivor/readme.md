Parenting Survivor V10
Static HTML game; no build tools or dependencies required.
GitHub Pages deployment
Copy `parenting_survivor/index.html` into the root of your HoveyBits GitHub Pages repository.
The game will be available at `/parenting_survivor/`.
The top navigation uses `../index.html` to return to the main HoveyBits home page.
Add a link on the HoveyBits home page:
```html
<a href="parenting_survivor/">Play Parenting Survivor</a>
```
V10 changes
Amazon packages pause the game and reveal the reward before applying it.
Accept the reward or return it for 10 stars. Returned stars increase the HUD star counter, not the XP meter.
Return to HoveyBits link in top navigation.
