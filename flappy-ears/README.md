# Flappy Ears — HoveyBits

A tiny, dependency-free HTML Canvas game. Fly a rabbit through rocky tunnel gaps and collect carrots.

## Publish to GitHub Pages

1. Upload this entire folder as `/flappy-ears/` in your GitHub Pages repository.
2. Open `https://YOUR-USERNAME.github.io/flappy-ears/` (or your configured Pages domain).
3. Add `<a class="button" href="flappy-ears/">🐰 Play Flappy Ears</a>` to your homepage.

## Controls

Tap, click, Space, or Up Arrow to flap. P pauses. Sound can be toggled. Best score and collected carrots are stored locally in the browser.

No external dependencies, accounts, ads, or network calls.
